# AI 컨텍스트 문서 체계 구성 — 개발 계획

| 항목 | 내용 |
|---|---|
| 대상 | `d94-app-ecc` |
| 참조 | `d94-app-umd`의 L1 저장소 가이드, L2 기능 패키지 가이드, docs의 현재 상태·기능 문서 |
| 목표 | 문서의 기본 언어를 한국어로 통일하고 작업 대상 기능에 필요한 문맥을 단계적으로 불러오도록 구성 |
| 날짜 | 2026-10-31 |

## 작업 범위

1. Python 코드를 API, Telegram, 티켓, 분류, 실행, 설정 기능 모듈로 구분한다.
2. L1 저장소 가이드에서 불변식, 모듈 지도, 변경·문서 동기화 규칙을 제공한다.
3. 각 L2 모듈 폴더에 `AGENTS.md`와 `CLAUDE.md` 쌍을 둔다.
4. L3 아키텍처 문서에 전체 요청 흐름, 경계, 환경 설정을 모은다.
5. L4 기능 문서에 API 계약, 상태 흐름, 실패 처리와 코드 위치를 기록한다.
6. README와 배포 문서를 한국어로 제공하고 로컬 Compose 운영 및 선택적 Eureka 연결을 설명한다.

## 완료 기준

- README, L1/L2, 아키텍처, 기능·배포 문서가 한국어로 작성됨.
- L1에서 L2~L4 문서로 이어지는 경로가 확인 가능함.
- 코드 파일 배치와 문서의 모듈 지도·코드 링크가 일치함.
- Python 문법 검사와 문서 링크 검사를 수행하고 결과를 기록함.
